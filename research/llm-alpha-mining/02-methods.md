# 方法拆解:LLM 挖因子的原理与设计空间

## 1. 任务形式化

**目标**:寻找因子表达式 f,使得每天对全体股票计算出的因子值,与未来收益(通常 1–10 日)的截面相关性稳定为正(或负)。

**数据词表**(以 Alpha101 / Qlib 惯例为准):
- 量价:`open, high, low, close, volume, vwap, returns`
- 衍生:`adv{d}`(d 日平均成交额)、行业分类 `industry`
- 扩展:基本面字段(财报)、另类数据(情绪分、新闻计数)——LLM 方法的优势区,符号搜索难以利用

**操作符体系**(表达式 = 操作符的嵌套组合):
| 类别 | 例子 | 说明 |
|------|------|------|
| 元素级 | `log, abs, sign, +, -, *, /` | 逐元素运算 |
| 时序 | `delay(x,d), delta(x,d), ts_mean, ts_std, ts_rank, ts_max, ts_argmax, ts_corr(x,y,d), decay_linear` | 沿时间轴回看 d 天 |
| 截面 | `rank(x), scale(x), indneutralize(x, industry)` | 当天对全体股票做排名/标准化/行业中性化 |
| 条件 | `x < y ? a : b` | 分支逻辑 |

示例(Alpha101 #6):`-1 * ts_corr(open, volume, 10)` — 开盘价与成交量 10 日相关性的负值。

## 2. 评价指标(所有方法共用的"打分器")

| 指标 | 含义 | 经验及格线(A 股日频参考) |
|------|------|--------------------------|
| IC / RankIC | 因子值与次期收益的截面(秩)相关,逐日计算取均值 | \|IC\|>0.02 可看,>0.05 优秀 |
| ICIR | IC 均值 / IC 标准差 | >0.3 可看,>0.5 优秀 |
| 分层回测 | 按因子值分 5–10 组,看组间收益单调性与多空价差 | 单调 + 多空年化显著为正 |
| 换手率 | 因子排序日间变化幅度 | 结合费率折算,高换手因子扣费后常归零 |
| 增量性 | 与既有因子库的相关性 / 正交化后残余 IC | 与库内因子相关 <0.7,残余 IC 仍显著 |
| 衰减 | 样本外/上线后 IC 的时间衰减速度 | 半衰期越长越好 |

## 3. 六大方法族对比

| 方法族 | 代表作 | 生成方式 | 优点 | 弱点 |
|--------|--------|---------|------|------|
| 遗传规划 (GP) | gplearn 路线 | 表达式树随机变异/交叉 | 简单、可并行 | 产出难解释、同质化重、易过拟合 |
| RL 序列生成 | AlphaGen、QuantFactor REINFORCE | 策略网络逐 token 生成表达式 | 可把**组合增量**做成奖励(关键创新) | 训练不稳、搜索空间大 |
| MCTS | RiskMiner | 树搜索 + 回测打分 | 探索有方向性 | 计算昂贵 |
| LLM 提示生成 | Alpha-GPT、Chain-of-Alpha | 自然语言假设 → 表达式 | **有市场逻辑先验**、可解释、能用另类数据 | 复述训练语料里的经典因子(最大风险) |
| LLM + 进化/记忆 | QuantaAlpha、AlphaMemo、FactorMiner、AlphaPROBE | LLM 做语义引导的变异算子,记忆历史搜索轨迹 | 兼得先验与探索;经验可积累 | 系统复杂、评估成本高 |
| LLM 多智能体全流程 | AlphaAgent、R&D-Agent(Q)、AlphaLogics | 假设 agent + 编码 agent + 评审 agent 闭环 | 端到端自动化,因子与模型协同优化 | token 成本高;效果依赖回测器质量 |

**核心洞察**:LLM 相对符号搜索的真正优势不是"搜得快",而是 (1) 带市场逻辑先验,产出可解释的假设驱动因子;(2) 能读财报/新闻,把另类数据纳入表达式;(3) 能从回测报告的自然语言反馈中"理解"失败原因并定向改进。纯粹在量价表达式空间里拼搜索效率,RL/GP 未必输。

## 4. 三大防御机制(区分玩具系统与严肃系统的分水岭)

### 4.1 防复述(originality)
- **AST 相似度查重**(AlphaAgent):新因子的语法树与因子库(含 Alpha101、已挖因子)比对,超阈值即拒绝。
- 语义查重:LLM 判断新因子与已知因子是否同一逻辑的变体。

### 4.2 防过拟合(complexity control)
- 表达式复杂度约束:AST 节点数/深度上限,惩罚"魔法常数"。
- 假设-因子对齐(AlphaAgent):因子必须能被它声称的市场假设解释,防止无逻辑的数字炼金。
- 统计折减:多重检验校正 —— [Deflated Sharpe](https://scholar.google.com/scholar?q=%22The+Deflated+Sharpe+Ratio%22)、[Harvey-Liu haircut](https://scholar.google.com/scholar?q=%22Backtesting%22+Harvey+Liu+haircut);挖了 N 个因子就要按 N 折减显著性。
- 严格样本外:训练/验证/测试期切断,测试期只碰一次。

### 4.3 防同质化与衰减(synergy & decay)
- 以**组合增量**为目标(AlphaGen):奖励 = 新因子加入组合后整体表现的提升,而非单因子 IC。
- 相关性惩罚:与库内因子相关性进入负奖励。
- 衰减监测:滚动窗口 IC 趋势;上线后设淘汰机制。

## 5. LLM 特有的偏差问题

与"LLM 直接预测价格"不同,挖因子的回测是传统回测,前视偏差风险低一个量级——但仍有两个 LLM 特有的泄漏渠道:

1. **知识泄漏**:LLM 从文献中"知道"哪类因子历史上有效(如 2015 年后低波异象拥挤),它生成的因子在历史回测里占便宜,但这种优势不代表未来。缓解:更看重**近期滚动窗口**与真正上线后的表现。
2. **评测集污染**:如果用公开基准(如 Alpha101 在某段行情的表现)对比,LLM 可能见过相关分析。缓解:自建时段、自建股票池。

## 6. 评测协议(验收一个挖因子系统)

参照 [AlphaEval](https://arxiv.org/pdf/2508.13174) 的思路,至少覆盖五个维度:
1. **预测力**:IC/RankIC/ICIR(样本外)
2. **投资价值**:分层多空、扣费后收益、容量估计
3. **稳定性**:跨时段、跨股票池、跨市场状态(牛/熊/震荡)的 IC 稳定性
4. **多样性**:因子集内部相关性矩阵、对既有库的增量
5. **可解释性**:每个因子是否有站得住的市场假设

再加两条工程指标:单位算力/token 成本产出的合格因子数;从假设到回测完成的循环时长。
