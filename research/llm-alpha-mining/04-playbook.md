# 实操手册:用 Claude 跑一轮 LLM 挖因子

> 本手册写给 Claude Code 会话(或任何 LLM agent)直接执行。前提:已按 [03-tooling.md](./03-tooling.md) Step 1 配好 Qlib(或任何能算 IC/分层回测的打分管道)。
> 核心原则:**LLM 只生成假设和表达式,永远不让 LLM 给自己的因子打分**——打分只信回测管道的数字。

## 流程总览(一轮迭代)

```
市场假设 → 因子表达式(批量5-10个) → 静态检查(语法/查重/复杂度)
   ↑                                          ↓
反馈改进 ← 增量检验(vs 因子库) ← 回测打分(IC/分层/换手)
```

合格因子入库;连续 3 轮无合格因子则更换假设方向。

## Step 1:生成市场假设

提示词模板:

```
你是量化研究员。基于以下市场逻辑方向之一,提出 3 个具体、可检验的市场假设:
- 行为偏差(过度反应/反应不足/羊群/处置效应)
- 微观结构(量价背离/流动性/买卖压力)
- 信息扩散(龙头-跟随/行业内传导)
- 风险补偿(波动/偏度/尾部风险)

要求:每个假设必须说明 (1) 谁犯了什么错或承担了什么风险 (2) 为什么这个错误/补偿会持续存在
(3) 预期因子方向。禁止直接复述教科书因子(动量/反转/低波的原始形式)。
```

## Step 2:假设 → 因子表达式

```
将以下假设翻译为公式化因子。可用字段:open, high, low, close, volume, vwap, returns。
可用操作符:
- 元素级:+ - * / log abs sign
- 时序:delay(x,d) delta(x,d) ts_mean(x,d) ts_std(x,d) ts_rank(x,d) ts_corr(x,y,d) decay_linear(x,d)
- 截面:rank(x) scale(x)

约束:AST 节点数 ≤ 15;回看窗口 d ∈ [3, 60];禁止无意义的魔法常数;
每个因子附一行"该表达式如何体现假设"的说明。输出 5 个候选,JSON 数组:
[{"expr": "...", "hypothesis": "...", "rationale": "...", "direction": "+1 或 -1"}]
```

## Step 3:静态检查(代码执行,不走 LLM)

按顺序过滤,任何一条不过即丢弃:
1. **语法**:表达式可被解析器解析、字段与操作符在白名单内。
2. **查重**:与因子库(含 Alpha101 与已入库因子)做 AST 相似度;等价变换归一化后(交换律排序、常数归一)相似度 > 0.8 则拒绝。
3. **复杂度**:AST 节点数 ≤ 15、深度 ≤ 6。
4. **数值健康**:随机抽 100 只股票试算,NaN/Inf 比例 < 5%,截面方差非零。

## Step 4:回测打分(代码执行,不走 LLM)

对每个存活因子,在**训练期**(如 2018–2022)计算:
- RankIC 均值、ICIR、IC 为正的月份占比
- 10 分组分层:组间单调性(Spearman)、Top-Bottom 多空年化、扣费后(A 股按双边 ~0.15% 起)多空年化
- 日均换手率
- 与因子库每个因子的截面相关性(取最大值)

**合格线(日频、全市场股票池参考值,按自己市场调整)**:
`|RankIC| ≥ 0.02 且 ICIR ≥ 0.3 且 分层单调 p<0.05 且 扣费多空 > 0 且 max_corr < 0.7`

## Step 5:反馈迭代

把回测报告喂回 LLM:

```
以下是你上一批因子的回测结果:{JSON 报告}
逐个诊断失败原因(IC 太低=假设不成立?换手太高=信号太快?与库内因子相关=换皮?),
然后:对最有希望的 1-2 个做定向修改(如加 decay_linear 降换手、加 rank 去极值),
并提出 1 个新方向。输出格式同前。
```

## Step 6:入库与终检(防过拟合的最后闸门)

- 通过 Step 4 的因子先进"候选库",**不看测试期**。
- 全部挖掘结束后,候选因子在**测试期**(如 2023–2024,只用一次)复算 Step 4 指标;RankIC 保持同号且 ≥ 训练期一半才转正。
- 对整个挖掘过程做多重检验折减:记录总尝试因子数 N,用 Deflated Sharpe / Bonferroni 意识评估"最好那几个"是否仍显著。
- 记录每个因子的:表达式、假设、挖掘日期、训练/测试期指标——上线后按月监控 IC 衰减,半衰期过短即退役。

## 常见坑清单

| 坑 | 症状 | 解法 |
|----|------|------|
| LLM 复述经典因子 | 挖出的全是动量/反转变体 | 查重阈值调严;提示词里明确禁止;假设先行 |
| 未来函数 | 回测异常好 | 表达式白名单里不允许任何前视字段;`delay` 方向审计 |
| 幸存者偏差 | 全市场回测虚高 | 用含退市股票的点位(PIT)股票池 |
| 测试期被反复使用 | 测试期指标越来越好 | 测试期只碰一次;需要更多验证就再切一段 |
| 高换手吃掉收益 | IC 好但扣费归零 | 把扣费后多空写进合格线;奖励里惩罚换手 |
| 极值驱动 | IC 靠几只妖股 | 截面 rank/winsorize;分层看单调性而非只看多空 |
| LLM 自评过拟合 | 让 LLM 挑"最好的因子" | 永远只用回测数字排序,LLM 只负责生成与诊断 |

## 给调用本手册的 Claude 会话的执行建议

1. 先读 `02-methods.md` 第 1、2 节确认语法与指标口径;
2. 用 Python 实现 Step 3/4 的管道(Qlib 或 pandas 皆可),**先用 Alpha101 里的 2 个已知因子验证管道输出合理**;
3. 再进入 Step 1–5 的循环,每轮把状态(候选/合格/淘汰及原因)写进一个 `mining_log.md`;
4. 任何时候不确定指标口径,以本文件夹文档为准,不要即兴发明。
